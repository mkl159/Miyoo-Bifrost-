===========================================================
  GUIDE D'INSTALLATION - BIFROST DUAL BOOT
  Miyoo Mini / Mini Plus / Mini Flip
  OnionOS v4.3.1-1 (ou v4.4.0-beta) + TelmiOS v1.10.3
===========================================================

Bifrost affiche un menu au demarrage de la console pour
choisir entre OnionOS (retrogaming) et TelmiOS (histoires).

Ce guide decrit l'installation automatique, puis la
procedure manuelle pour ceux qui la preferent.

-----------------------------------------------------------
PREREQUIS
-----------------------------------------------------------
- Une carte SD, formatee en FAT32.
  ATTENTION : FAT32 est obligatoire, quelle que soit la
  taille de la carte. Le firmware Miyoo ne demarre pas sur
  une carte exFAT ou NTFS. Windows refuse de formater en
  FAT32 au-dela de 32 Go : l'installateur Bifrost sait le
  faire, sinon utilisez Rufus (https://rufus.ie) avec une
  taille d'unite de 32 Ko.

- Les deux archives d'OS, decompressees :
  . OnionOS : https://github.com/OnionUI/Onion/releases
  . TelmiOS : https://github.com/DantSu/Telmi-story-teller/releases

- Python n'est PAS necessaire : les images du menu sont
  deja incluses dans DualBoot/.tmp_update/res/.

===========================================================
  METHODE 1 - INSTALLATION AUTOMATIQUE (recommandee)
===========================================================

Windows
-------
1. Placez dans un meme dossier :
     INSTALLER_BIFROST.exe
     DualBoot\
     le dossier OnionOS decompresse   (ex: Onion-v4.3.1-1\)
     le dossier TelmiOS decompresse   (ex: TelmiOS_v1.10.3\)
2. Double-cliquez sur INSTALLER_BIFROST.exe.
   Il demande les droits administrateur (necessaires pour
   formater la carte).
3. Choisissez la lettre de la carte SD, puis les deux
   dossiers d'OS quand ils sont demandes.
4. Un journal complet est ecrit sur le Bureau, dans
   bifrost_install.log.

macOS
-----
   Ouvrez le Terminal, puis :
     ./install_macos.sh

===========================================================
  METHODE 2 - INSTALLATION MANUELLE
===========================================================

ETAPE 1 - Formater la carte en FAT32
------------------------------------
Sauvegardez d'abord vos ROMs, histoires et sauvegardes.
Formatez ensuite en FAT32, taille d'unite 32 Ko.

ETAPE 2 - Copier le bootloader
------------------------------
  DualBoot\.tmp_update\   ->  SD:\.tmp_update\
  DualBoot\autorun.inf     ->  SD:\autorun.inf

ETAPE 3 - Copier les binaires d'OnionOS
---------------------------------------
  <OnionOS>\miyoo\app\.tmp_update\bin\  ->  SD:\.tmp_update\bin\

ETAPE 4 - Copier les librairies de TelmiOS
------------------------------------------
Celles de TelmiOS sont plus completes (SDL 1.2 et SDL 2).
Utiliser celles d'OnionOS provoque un redemarrage en boucle.

  <TelmiOS>\.tmp_update\lib\  ->  SD:\.tmp_update\lib\

ETAPE 5 - Copier l'updater d'OnionOS
------------------------------------
  <OnionOS>\.tmp_update\updater  ->  SD:\.tmp_update\updater

ETAPE 6 - Installer les deux OS dans leurs sous-dossiers
--------------------------------------------------------
  tout le contenu de <TelmiOS>  ->  SD:\telmios\
  tout le contenu de <OnionOS>  ->  SD:\onion\

ETAPE 7 - Placer les donnees TelmiOS a la racine
------------------------------------------------
Telmi-Sync lit les histoires a la racine de la carte, pas
dans telmios\. Deplacez donc ces trois dossiers :

  SD:\telmios\Stories\  ->  SD:\Stories\
  SD:\telmios\Saves\    ->  SD:\Saves\
  SD:\telmios\Music\    ->  SD:\Music\

Bifrost les remonte automatiquement pour TelmiOS au
demarrage : rien d'autre n'est a faire.

ETAPE 8 - Declarer la version pour Telmi-Sync
---------------------------------------------
Telmi-Sync reconnait la carte grace au libelle de
SD:\autorun.inf. Faites-le correspondre a la version de
TelmiOS que vous venez d'installer, par exemple :

  [autorun]
  icon  = .tmp_update/res/sdcard.ico
  label = TelmiOS-v1.10.3

Verifiez aussi que SD:\Saves\.parameters existe et
contient du JSON valide : Telmi-Sync le lit sans verifier
sa presence, et echoue a detecter la carte s'il manque.
En cas de doute, copiez celui de l'archive TelmiOS.

===========================================================
  STRUCTURE FINALE DE LA CARTE
===========================================================

  SD:\
  +-- .tmp_update\           <- BOOTLOADER BIFROST
  |   +-- runtime.sh         <- menu de selection
  |   +-- bin\               <- binaires (depuis OnionOS)
  |   +-- lib\               <- librairies (depuis TelmiOS)
  |   +-- updater            <- depuis OnionOS
  |   +-- config\
  |   |   +-- dualboot.cfg   <- reglages du menu
  |   +-- res\
  |       +-- bootmenu_*.raw <- images du menu (FR/EN/ES)
  |       +-- sdcard.ico
  +-- telmios\               <- TelmiOS complet
  +-- onion\                 <- OnionOS complet
  +-- Stories\               <- histoires (vues par Telmi-Sync)
  +-- Saves\                 <- sauvegardes TelmiOS
  +-- Music\                 <- musiques
  +-- autorun.inf

Les fichiers .raw sont des images brutes ecrites directement
sur le framebuffer, en 640x480 pour le Mini et le Mini Plus,
et en 752x560 (suffixe _flip) pour le Mini Flip. Bifrost
detecte la resolution et choisit le bon jeu d'images.

===========================================================
  UTILISATION DU MENU
===========================================================

  Gauche / Droite   choisir l'OS
  A                 confirmer et demarrer
  X                 ouvrir la configuration
  SELECT            annuler / revenir en arriere

Sans action pendant 60 secondes, le dernier OS choisi
demarre automatiquement. Le choix est memorise dans le
fichier .bootchoice a la racine de la carte.

Le menu de configuration (touche X) permet de regler la
langue, les vibrations, un code de verrouillage par OS, le
mode de demarrage furtif et le Code Konami. Ces reglages
sont aussi modifiables a la main dans
SD:\.tmp_update\config\dualboot.cfg.

===========================================================
  DEPANNAGE
===========================================================

Ecran noir au demarrage
  Verifiez la presence de SD:\.tmp_update\runtime.sh,
  du dossier bin\ et du dossier lib\.
  Consultez SD:\.tmp_update\logs\dualboot.log : Bifrost y
  ecrit chaque etape de son demarrage.

La console redemarre en boucle
  Les librairies de SD:\.tmp_update\lib\ doivent venir de
  TelmiOS, pas d'OnionOS.

Le menu s'affiche mais reste noir apres le choix
  Verifiez que SD:\telmios\ et SD:\onion\ contiennent bien
  les fichiers des OS.

OnionOS ne demarre pas au premier essai
  Normal : l'installateur interne d'OnionOS se lance et
  prend environ deux minutes.

Telmi-Sync ne reconnait pas la carte
  Le libelle de SD:\autorun.inf doit commencer par
  TelmiOS-v suivi d'une version a trois nombres, et
  SD:\Saves\.parameters doit contenir du JSON valide.

Le menu Bifrost a disparu apres une mise a jour Telmi-Sync
  Le bouton "mettre a jour TelmiOS" de Telmi-Sync ecrit a la
  racine de la carte et remplace le bootloader. Relancez
  l'installateur Bifrost pour le restaurer ; les histoires
  et les reglages sont conserves.

===========================================================
  NOTES
===========================================================
- Les ROMs vont dans SD:\onion\Roms\ pour OnionOS.
- Les histoires vont dans SD:\Stories\ (racine) pour TelmiOS.
- Les sauvegardes des deux OS restent separees.
- Le Wi-Fi fonctionne normalement dans chaque OS.
